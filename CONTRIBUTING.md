# Contributing

## Fluxo recomendado

1. Escolha um módulo/issue de escopo pequeno.
2. Leia a documentação e ADRs relevantes.
3. Crie branch curta a partir da branch principal.
4. Implemente em incrementos pequenos.
5. Adicione testes e telemetria.
6. Atualize documentação.
7. Abra PR usando o template do repositório.

## Commits

Use Conventional Commits. Consulte `docs/development/commits.md`.

## Architecture changes

Mudanças que alteram fronteiras de serviço, tecnologia fundamental, ownership de dados, protocolo, topologia, modelo de tenancy ou estratégia de segurança exigem ADR.

## Pull requests

PRs devem explicar: problema, solução, impactos, testes, observabilidade, segurança, migração e rollback quando aplicável.
