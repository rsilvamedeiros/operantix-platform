# Implement NestJS Module

1. Read domain and NestJS rules.
2. Define application boundary and domain invariants.
3. Keep controllers thin.
4. Validate DTOs at the edge.
5. Enforce authorization/TenantContext.
6. Keep infrastructure adapters replaceable.
7. Add unit + integration tests appropriate to the change.
8. Add telemetry at meaningful operations.
9. Update OpenAPI/docs.
