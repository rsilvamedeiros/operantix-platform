# Architecture Decision Records

## Status

`Proposed`, `Accepted`, `Superseded`, `Rejected`.

## Rule

ADR Accepted não é reescrito para esconder história. Se a decisão mudar, crie novo ADR e marque o anterior como Superseded.

## Template

```md
# ADR-NNNN — Title
Status: Proposed
Date: YYYY-MM-DD

## Context
## Decision
## Consequences
## Alternatives
## Follow-up
```
