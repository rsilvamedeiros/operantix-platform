# Definition Of Done

- [ ] Código compila/typecheck
- [ ] Lint/format passam
- [ ] Testes relevantes passam
- [ ] Authorization/tenant isolation verificados
- [ ] Logs/traces/metrics adicionados quando aplicável
- [ ] Sem secrets/hardcoded credentials
- [ ] Docs e contratos atualizados
- [ ] Migration revisada quando houver
- [ ] Erro/rollback/retry paths considerados
- [ ] PR explica riscos e validação
