# MVP

O MVP técnico não precisa suportar todas as capacidades planejadas.

## Deve conter

- login e usuário local/provedor definido;
- organization/workspace;
- RBAC básico;
- criação de workflow simples;
- trigger manual/API;
- execution + steps;
- worker assíncrono;
- um connector HTTP;
- um step de IA;
- timeline observável;
- OpenTelemetry básico;
- PostgreSQL + Redis;
- testes críticos.

## Depois do MVP

Kafka, connectors adicionais, MongoDB quando houver caso real, billing, analytics avançado, DynamoDB, Kubernetes e Temporal.
