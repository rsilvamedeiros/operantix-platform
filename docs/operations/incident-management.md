# Incident Management

## Severity draft

- SEV1: indisponibilidade ampla, cross-tenant/security incident ou perda de dado crítica.
- SEV2: feature central degradada/alto erro sem workaround adequado.
- SEV3: degradação limitada com workaround.

## First actions

1. confirmar impacto;
2. conter blast radius;
3. preservar evidência/trace IDs;
4. estabilizar antes de otimizar;
5. comunicar status;
6. registrar timeline;
7. post-incident review com ações concretas.
