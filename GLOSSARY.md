# Glossary

- **Organization**: unidade de conta/cliente do Operantix.
- **Workspace**: espaço operacional isolado dentro de uma Organization.
- **Tenant**: boundary lógico de isolamento de dados; inicialmente correlacionado a Organization/Workspace conforme domínio.
- **Workflow**: definição versionada de automação.
- **Execution**: uma execução concreta de um Workflow.
- **Step**: unidade de trabalho dentro de uma Execution.
- **Trigger**: evento que inicia um Workflow.
- **Integration**: conexão com sistema externo.
- **Agent**: capacidade de IA com instruções, ferramentas e políticas definidas.
- **Event**: fato imutável publicado por um producer.
- **Command**: intenção para que um componente execute uma ação.
- **DLQ**: dead-letter queue/topic para mensagens que esgotaram tentativas.
- **Idempotency**: garantia de que reprocessar a mesma operação não cria efeitos duplicados.
- **Trace**: cadeia correlacionada de spans de uma operação distribuída.
- **ADR**: Architecture Decision Record.
